# Security

This project indexes local `SKILL.md` files and builds request text. It does not download or execute skill scripts. Treat skill directories and generated request text as untrusted input when integrating the runtime into a host application.

After the repository is created, suspected vulnerabilities can be reported through GitHub's private vulnerability reporting if the repository owner has enabled that feature:

<https://github.com/YeFengLeaf/skill-runtime/security/advisories/new>

The form's availability depends on the repository and its security settings; this link is not evidence that private reporting is currently enabled. If the form is unavailable, contact the maintainer through the `YeFengLeaf` GitHub profile and request a private channel. Do not disclose suspected vulnerabilities in a public issue or include secrets or personal data.
