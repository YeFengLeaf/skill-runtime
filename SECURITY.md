# Security

This project indexes local `SKILL.md` files and builds request text. It does not download or execute skill scripts. Treat skill directories and generated request text as untrusted input when integrating the runtime into a host application.

Please report suspected vulnerabilities through GitHub's private vulnerability reporting for this repository once it is enabled. Until then, contact the maintainer privately through the `YeFengLeaf` GitHub profile. Do not include secrets or personal data in a public issue.
